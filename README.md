# Authoritative Data Registers

The Authoritative Data Registers (ADR) team supports authoritative data registers for Connected Services BC.

This team sits within the Policy Direction division of Connected Services BC, in the Data Governance & Sovereignty (DIGS) branch.

## Documentation

Documentation published to DevHub is located in the [Documentation/Devhub folder](./Documentation/Devhub). `catalog-info.yaml` and `mkdocs.yml` are located in the project root to best support DevHub dynamic catalog imports.
